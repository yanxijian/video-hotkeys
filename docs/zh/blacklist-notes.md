# 内置黑名单：决策记录

本文记录内置黑名单（脚本内的 `BLACKLIST` 常量）每一条决策的依据、置信度与验证状态。
默认名单是 **agent（AI 助手）提议、维护者默许** 的快照，不是逐站实测的产物——把这一点写公开，
是为了以后讨论增删时有据可查，也为了让「AI 知识快照」的血统不被埋没。

治理原则（全文适用）：

1. 默认值的举证责任在提议方（agent），维护者默许 ≠ 背书；
2. 面板保证默许随时可被推翻：内置条目只能禁用、不能删除，用户可自由新增；
3. 存储只记「相对默认值的差异」（added/disabled），脚本更新带来的新内置条目自动生效；
4. 本脚本拦截按键使用 capture 阶段 + `stopImmediatePropagation`——**接管即杀掉站点自己的
   监听器**，所以「冲突成本」是让路决策的首要判断依据，而不是「对方有没有快捷键」。

## 置信度分级

| 级别 | 含义 |
| --- | --- |
| A | 官方文档：站点帮助页公开列出快捷键表 |
| B | 训练知识：agent 的模型知识，未实测，可能过时 |
| C | 结构性冲突：不依赖快捷键表的方向键语义冲突 |
| D | 实测：维护者在真实站点逐键验证（目前没有站点达到此级） |
